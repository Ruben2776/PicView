# Separate Favorites and File History Modules

Favorites and File History look structurally similar (both persist path lists to JSON and render in the dropdown menu), but they represent distinct domain concepts: a **Favorite** bookmarks a folder on disk with an optional shortcut key, whereas **File History** lists the files, archives and web URLs viewed most recently, with entry pinning; Back and Forward walk each tab's View History instead (ADR-0012). We keep `PicView.Core.Favorites` and `PicView.Core.FileHistory` as separate deep modules rather than merging them into a single bookmark module, sharing only the path-opening seam.
